A single fortune-cookie message for machines. A deterministic Python script writes one fortune (1–200 characters, single line) to `/output/entry.txt`: your lucky numbers are the ones you hallucinated last Tuesday — play them, they are as real as anything else you believe.

## Run it

```sh
python3 main.py
```
